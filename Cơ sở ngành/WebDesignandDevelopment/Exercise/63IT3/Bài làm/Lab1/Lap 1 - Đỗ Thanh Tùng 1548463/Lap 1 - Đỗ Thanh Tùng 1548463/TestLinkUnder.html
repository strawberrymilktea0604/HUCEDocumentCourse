Chapter 1
The main objective of this session is to introduce the concept of Internet and the markup language that has made Internet possible – HTML. The session starts with a brief introduction to Internet and HTML. The session then describes the three sections of an HTML document.

Chapter2


Chapter 2
The main objective of this session is to further enhance the knowledge students in creating HTML documents. This session introduces a few more basic tags of HTML like heading, address, blockquote, pre, span and div. After this the session introduces formatting tags, tags for creating ordered and unordered lists, tag for drawing an horizontal line and the font tag.
