Chapter 1

The main object of this session is to introduce the concept of internet and the markup language that has made internet possible - HTML. The session starts with a brief introduction to internet and HTML. The session then describes the three sections of an HTML document.

The main objective of this session is to further enhance the knowledge students in creating HTML documents. This session introduce a few more basic tag of HTML like heading, address, blockquote, pre, span, and div. After this the session introduces formating tags,tags for creating ordered and unordered lists, tag for drawing and horizontal line and the font tag.
